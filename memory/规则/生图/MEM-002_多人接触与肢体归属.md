# 多人接触与肢体归属

适用：画面中不同人物发生搀扶、拉拽、拥抱或手臂/手掌交叠等身体接触。多人同框但无接触，不自动要求新增辅助图。

镜头阶段：从批准动作确定每条可见肢体所属人物、起点终点、接触位置和前后遮挡。左右以明确的角色自身/画面坐标描述，不混用。未知动作或身体关系先解决，不猜。复杂关系确有必要时补辅助图，已有充分参考时复用。

生图阶段：把当前可见接触关系、手臂所属角色和遮挡写进实际提示词；不得为展示完整肢体改变批准动作、移开遮挡物或拉大全景。

返回图阶段：实际检查 hand_ownership（每只手与手臂归属、合理数量）、contact_geometry（接触点与关节动作）、occlusion（前后与遮挡）。不以“姿势大致像”代替逐处检查。发现多手、断肢或手臂接错人则定点修复，保留批准身份服装与动作意图。

具体检查沿肩—肘—腕—掌逐处确认归属、接触与前后层次。持杯/扶人/抓物明确角色自身左右、拇指位置及遮挡；不要求被真实遮挡的五指全部露出。审图记录实际部位及观察差异，不能仅复述动作预期。

先全图逐人物核对数量与闭合归属，再看局部接触：每只可见掌、腕、袖口只能属于一条合理肢体，沿肩—肘—腕—掌追踪；合理遮挡允许连接部分不可见，但须有连续路径依据。不能因局部已经托住对象就忽略原处另留的一只手。

同一时刻按自身左右明确手的任务。递接物写清当前承重者、接收者和接近/接触/接稳阶段；可以两人同时接触同物，不能为每个接触点生成一条新手臂。结构返修需明确旧结构移除、新结构替换及所属连接，返图重新数整个人物的肢体并核对承托，局部正确不抵消整体多手。
