# 局部返修保留批准特征

适用：对已返回图片进行局部修复。实际操作必须标记 operation=repair，无须在批准镜头中预先虚构返修事件。

生图阶段：记录明确修复目标、允许改动范围、必须保留的已批准特征及受影响连续性。每次实际调用继续提交原始批准画风和适用身份/衣装参考，不能仅以错误图为唯一依据。把当前修复范围和保留约束写入实际提示词。用户明确批准的换装、改构图等属于本次允许改动，不应被通用保留规则否定。

返回图阶段：检查 repair_scope（目标确已修复）、identity_preserved（批准身份）、style_preserved（原始画风）、costume_preserved（本次适用衣装）、unaffected_composition（未授权变化的构图与动作）。范围内变更记录当前授权依据，不虚报保留。修复成功仍需全套图片质量及邻格连续性检查。

一次针对性返修仍有同一问题时停止诊断，不无限抽卡。局部事实、具体错误格、人物与服装名称只写入生产任务，不进入通用规则库。

返修选择本格已记录的清晰原始返回底图，说明选择理由并保留此前有效修正；不机械沿用最早或最新版本。红字标注、缩略图不作底图。返回后在可比尺度检查焦内线条、首饰、手部及未授权区域，尺寸或PNG格式不能单独证明无退化。

既有图片按真实缺陷区分裁切候选、局部返修与需改镜头的重绘。图本身正确仅背景过多可提出裁切，保留必显信息、目标比例和有效像素；超出批准构图范围按原流程解决。不能裁掉关键手势或矛盾空间虚报修复。文件名“修改版”不代表修复或验收通过，原图保留、改版另存并实际查看。

## 条件式坐标定位

已看实图且错误可定位、正确目标有批准依据、主要动作/机位/空间关系成立时，优先采用区域与锚点描述局部返修。整间房布局变化、机位错误或全局透视扭曲不通过拆框处理；局部范围按影响关系判断，不以景别或面积机械决定。

实际提示词骨架：“编辑底图为【真实别名】；左上(0%,0%)、右下(100%,100%)，x向右、y向下。编辑【对象/区域】；删除【旧错误及残留】，恢复【底层衣料/体表/背景】；重建【唯一正确结构】，从【根部/关节/安装点】连接至【末端/接触点】；保护【正确对象及特征】，只允许【必要连接过渡】；修复后【具体可见数量、连接或直边判据】。保持批准机位、画幅与遮挡，不绘制坐标和框线。”

每次用实际底图重新确定坐标，不复用旧图或参考子图的坐标。用户点击仅是问题线索，区域应覆盖错误结构和必要连接。移动结构分别说明旧位置删除、新位置重建与连接；旧新结构不并存。保护区与编辑区重叠时写清对象优先级，不能要求同一处既重画又逐像素不变。文字坐标不是硬蒙版。

人体肢体按MEM-002/006核对归属与可见连接；动物结构仅在命中MEM-012时读取物种专项，不套用人体模板。数量按本构图可见部分及批准缺肢/遮挡确定，不为凑齐数量补画画外肢体。

台面、窗框、建筑与家具硬边指定必要线段两端、角点、平面和厚度关系；删除旧弧线再重建，不能叠第二套边。保留合法透视斜线、批准曲面及软垫受力起伏；边缘允许出画和遮挡，不为展示完整而弯回画内。局部道具按批准安装根部、轴线与末端重建；批准设计没有的部件属于设计变更。

repair_scope按可观察目标逐项检查旧结构消失、新结构唯一、位置/连接/数量及接触；unaffected_composition检查整主体和正确内容未退化，其余三个检查ID继续核对身份、画风和衣装。位置改善不等于指趾/关节正确，目标改善不等于整图通过。复用原QA，不新增整图重复审核、返修轮次或成功保证。具体格号、坐标、动作变体与测试结果留在任务记录。

## 空间问题的限定返修

先将真实失败区分为局部刚性边、投影冲突、空间连接、承托凭空增加、构图压力或范围未确定。只有布局和机位已核对成立，问题限于具体刚性边时，才做局部直线连续性修复；可按现有坐标方法定位，但坐标不是硬遮罩或像素锁。

门窗换墙、楼梯断接、房间重组及不兼容的投影先修受影响输入与取景；构图压力先核对必显线索和可省略内容。不得把整体错误拆成几个小框，也不得把“统一透视”当作已验证必成功的修复。失败底图只继承已正确要素，不能把错误布局作为几何依据。

实际请求携带适用批准参考和清晰底图，明确修复对象、目标及保护范围。保留原光向、冷暖、曝光关系和人物受光；只有修复必然产生的局部接触阴影/遮挡变化在原授权范围内处理。生成后沿repair_scope与unaffected_composition复查结构、核心叙事、光线及此前正确内容，局部改善不表示整图通过。

复杂空间可有条件使用已核对空景再加人物；每个真实调用计入原预算，不能以中间资产名义重置轮次。空景后仍审成图。二轮失败保留实际观察与遗留问题，不循环强化措辞重抽。
