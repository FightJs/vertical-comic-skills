# 换机位保持固定空间锚点

适用：同一空间发生机位变化、反打或转向，需要保持场景连续。

镜头阶段：固定门窗、家具和关键道具的世界位置，先确定相机位置与朝向，再推导画面中的相对位置、可见面与遮挡。画面左右变化不等于物体在空间中移动。源剧情要求的真实移动另由当前镜头记录说明，不能由本规则禁止。

生图阶段：使用当前批准场景与镜头依据，在实际提示词写出本机位可见的锚点及其关系。不要把上格构图机械复制到反打，也不要为使背景好看而交换门窗。细节镜头可不见环境，不能强迫每格展示所有锚点。

返回图阶段：检查 fixed_anchors（与获批空间账一致）、camera_visibility（应见面和朝向）、occlusion（前后关系）。结合相邻已验收图与当前空间依据核对，不把上格错误图升为场景权威。

同场景共用固定关系来源，分别记录世界位置和本机位投影。验收对照具体锚点关系及同场景最近真实前序图；切场后返回仍承接原状态。仅墙色/灯饰相似不足以证明布局相同。

## 结构关系与唯一机位

建筑连接、门窗所属墙面、固定陈设排列和必要间距以批准参考为依据；先辨认实体关系，再推导目标机位投影。不把参考图画面左右当成所有机位都必须遵守的位置，不靠“布局不变”替代具体关系。参考未覆盖的连接保持未知，不凭空补成已确认结构。

仅当建筑/固定物件关系影响本格理解，或正在处理空间畸形时，选择本格必要关系进入执行包。无需完整重建房间、测量所有尺寸或展示全部锚点。涉及大幅转视角时保留足以核对必要关系的墙角、物件端部等证据；不为展示证据遗漏剧情主体。

当前镜头只有一套机位、人物站位和可见范围。衣装/配饰字段只负责身体锚点及其投影，不再定义人物世界位置；换机位、动作或裁切后，核对所有相关派生段落，不能只在末尾追加相反要求。固定承托由MEM-006判断，展示取舍由MEM-009判断。

验收沿fixed_anchors核对墙面归属与连接，camera_visibility核对一致投影，occlusion核对遮挡及其前后连续性。刚性直边的同一可见直线段不应局部弯折；同方向空间边按一致透视呈现。不同空间方向可以有不同消失点；不要求画面夹角等于90度，不强制水平/竖直，不误判合法透视缩短、镜头滚转、曲面或折角。未见区域不宣称看图通过。

此方法用于降低输入歧义和检查错误，不保证一次生成正确。复杂目标视角在直接生成失败后可按background-first路线考虑空景，但不能以成功空景替代加入人物后的重新检查。
