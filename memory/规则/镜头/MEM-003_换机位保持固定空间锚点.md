# 换机位保持固定空间锚点

适用：同一空间发生机位变化、反打或转向，需要保持场景连续。

镜头阶段：固定门窗、家具和关键道具的世界位置，先确定相机位置与朝向，再推导画面中的相对位置、可见面与遮挡。画面左右变化不等于物体在空间中移动。源剧情要求的真实移动另由当前镜头记录说明，不能由本规则禁止。

生图阶段：使用当前批准场景与镜头依据，在实际提示词写出本机位可见的锚点及其关系。不要把上格构图机械复制到反打，也不要为使背景好看而交换门窗。细节镜头可不见环境，不能强迫每格展示所有锚点。

返回图阶段：检查 fixed_anchors（与获批空间账一致）、camera_visibility（应见面和朝向）、occlusion（前后关系）。结合相邻已验收图与当前空间依据核对，不把上格错误图升为场景权威。

同场景共用固定关系来源，分别记录世界位置和本机位投影。验收对照具体锚点关系及同场景最近真实前序图；切场后返回仍承接原状态。仅墙色/灯饰相似不足以证明布局相同。
