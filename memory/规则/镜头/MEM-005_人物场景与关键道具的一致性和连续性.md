# 人物场景与关键道具的一致性和连续性

适用：画面中出现人物、场景或关键道具。镜头、生图、图片验收三个阶段均执行。

要求：人物身份、脸型、发型、当前服装及可见状态与批准依据一致；同一场景的结构、门窗、家具、光照条件与空间关系连续；关键道具的外观、尺寸、数量、持有者、摆放位置和状态变化均有脚本或获批动作依据。剧情明确发生的变化应准确表现，不能用“一致性”把它改回旧状态。

镜头阶段：确定本格人物/场景/道具状态，比较相邻格及相关前序状态。背景必须是从当前实际机位、朝向、高度和景别能够拍到的部分；不能机械复制前格背景，不能为适配新画面而移动场景结构。换机位同时执行 MEM-003。

生图阶段：核对原始批准人物、当前服装、场景及道具参考，写出本格真正可见的特征、背景区域和应保持/应变化的状态。裁切外的部分不必强行补入画面，前格候选不能替代原始批准依据。

图片验收：逐项记录 character_consistency（身份与当前外观）、scene_consistency（场景结构和条件）、key_prop_continuity（道具形态与状态）、camera_background_validity（背景与实际机位相符）、adjacent_state_continuity（邻格动作/持物/位置的变化有依据）。某类对象确实不出现时，在该检查依据中说明实际不可见或无此对象，不虚报已看见。无法确认的可见矛盾保持 HOLD。

连续性证据记录实际对照的参考版本及相邻格；跨批次不能重置。具体人物、服装、道具和坐标只留在本次制作记录，不写回通用规则库。

反复可辨认人物与背景人群区域持续保留在场状态；离场、画外与遮挡分开记录。重要首饰锁定可见形状、层数和佩戴位置，实际参考要能辨认相应细节。首饰、道具及机位连续性在原图与真实格组中比较，不以同色或同地点代替。

背景按本格获批叙事需要选择必要实景、实景柔化或轮廓概括；未启用新策略的旧包沿用其冻结clear_limited/获批景深。新制作禁止严重留白、纯色空底和无结构渐变；近景保留可辨识场景结构，再评估可简化范围，不设全话配额。颜色/光向来自当前批准场景状态。减少的是绘制细节，固定空间、人物在场、承托、接触、遮挡、关键道具及场景文字仍须成立；必要结构不能省略。纯色不等于虚化或低清，柔化仅限环境，人物五官、可见衣装首饰、动作手与对象保持清楚。场景参考不要求每格复现全套陈设。批准省略的环境实体保留在空间账本；画外/遮挡/离场与绘制省略区分。换回实景仍承接原状态，不能以同色证明布局一致。

可见关键首饰以清晰批准参考核对结构、层数、连接及人物自身佩戴侧/手指，不能凭同色判同款。原板不清楚则登记缺口，不猜造细节。独立细节/忠实图集按需引用，实际参考覆盖相应细节并遵守工具参考预算。

持续在场以世界状态为准：沉默、睡眠、切到他人反应不使人物离场。画外写明取景边界，遮挡写明具体遮挡物和覆盖部位；不能在原本可见的空床/座位上用“可能被挡”解释消失。布局比较选固定床头/床侧、路沿/车道等关系，不凭画面左右判断移位；当前格和前格都无法看清锚点时补较早有效原图，证据仍不足则保持未核实。

有正反面的道具同时满足使用者与摄影机观看关系：屏幕朝使用者，摄影机按真实机位看背/侧/正面。剧情必须读屏时改为可行的观看机位，不能把手机翻面或让角色盯着背壳；无需读屏则自然呈现背面。信息传递示意与真实物件区分，未批准的示意光线、图标不能实体化。道具相对手/头的尺寸稳定，近大远小须有统一透视依据。
