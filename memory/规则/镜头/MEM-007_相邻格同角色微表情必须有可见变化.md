# 相邻格同角色微表情必须有可见变化

适用：源阅读顺序中紧邻两格出现同一角色，且该角色两格面部均可用于判断表情。逐角色核查，不因画面焦点换人而跳过仍可见的同一角色；跨批次仍算相邻。

硬要求：不允许同一角色连续两格表情无变化。总体情绪可以连续，但必须设计并实际表现可辨认的微表情推进，例如眉形/眉间紧张度、眼睑开合、视线与眼部张力、嘴角、唇部或下颌状态的变化。只把“惊讶”改写为“震惊”，只换机位或只动身体但脸部没有变化，都不算通过。

镜头阶段：记录前后格相同角色的表情起点、变化点及剧情依据。生图阶段：在本格实际提示词写出具体可见的眉眼口部变化和情绪强度，避免与前格复制同一句模板；前格本来合格的身份与脸型保持不变。

验收阶段：对照实际相邻图逐角色确认 same_character_pair_basis（确为同角色和相邻格）、observable_expression_change（可见变化在哪里）、prompt_expression_specificity（提示词已写清）、emotion_story_fit（变化符合情绪节奏）。提示词不同但实图相同仍为 HOLD。

人物背向、面部完全遮挡或在画外时，不虚构“看见表情变化”；在镜头/验收记录说明该对无法比较表情，不为满足检查擅改批准裁切或强行露出正脸。无面部可比性不能拿来声称已经满足表情变化。若锁定脚本明确要求可见表情完全不变，记录冲突等待范围明确的处理，不能自行改剧情或默默放行。

具体角色及相邻格定位、实际图片版本/哈希只写入当次生产证据。

源稿明确的眼睑开合、唇部状态和视线聚焦状态是本格边界。微表情推进只在源稿及批准方案允许的范围内设计，不能为了制造变化将睁大眼改成略收、微张嘴改成闭嘴、酒后失焦改成专注。身份或衣装参考的默认表情不覆盖当前源稿。不同瞬间、人物及否定要求分别判断。

编译后核对完整实际prompt和检查判据，确认没有相反模板残留。面部不可见时仅排除不可观察的面部表现/比较，身份、发型、衣装和可见身体部位仍按适用判据审查。源稿与本规则确有冲突时仍保留原文并按准确范围处理，不静默豁免或改剧情。
