# 真实透视与遮挡优先于完整展示

适用：画面涉及真实前后遮挡、透视重叠，或完整展示人物/物品与物理空间发生冲突。镜头、生图、图片验收三个阶段均执行。

硬要求：如果当前机位实际存在遮挡，就保留遮挡。允许人物肢体或物品只露出一部分；不得为了完整展示而让桌椅、床沿、门框、家具、道具或其他人物让位、缩小、弯曲、穿透、透明化或改变形状。透视缩短按真实视角发生，不能拼成多个视角以同时露出全部结构。

镜头阶段：从批准空间和机位推导可见区域、前后顺序、遮挡边界与透视比例。信息不足时先在剧情与批准范围内重新设计合理机位并走必要审查，不能移动世界中的物体来迁就镜头。

生图阶段：在实际提示词具体说明“谁/什么挡住谁的哪部分”、应露出和应隐藏的部分及遮挡物稳定形态。不同时要求全身/完整物品与物理上必然的遮挡；不要追加通用的“完整展示四肢/所有道具”造成自相矛盾。

验收阶段：核对 physical_perspective（实际视角与透视）、occlusion_order（真实前后顺序）、occluder_geometry_preserved（遮挡物形状未扭曲）、no_visibility_driven_displacement（没有为了露出主体而无因移位）。脚本确实要求的物体移动按已批准动作表现，不能与为构图让位混淆。

与本批冻结的镜头规则共同执行：不为变化机位/景别破坏遮挡；有叙事依据的持续近景按适用规则核对，不能以假空间制造变化。

遮挡必须有具体实体、前后顺序和覆盖边界。手搭栏杆、握把或物件重叠时，从完整前臂到局部掌/指追踪接触，遮挡物的形状与后方连接保持相容；手靠近栏杆不能替代手真正搭在栏杆上。某侧被挡不能解释另一侧裸露结构消失。

证据不足与明确错误分开：合法透视缩短、真实画外和遮挡不自动判畸形；看不清归属或被遮挡部分时写出观察边界，保留待核实，不用假设生成PASS。
