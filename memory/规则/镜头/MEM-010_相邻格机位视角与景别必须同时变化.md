# 相邻格机位视角与景别必须同时变化

适用：源阅读顺序中的每一对相邻格，不以批次边界、换场景或执行者交接重置。首格确无前格时无比较对象；跨话有明确承接相邻关系时继续核对。

硬要求：相邻两格的机位/观察视角与景别两项必须同时有明确变化，不允许相同或实质相似。仅改一个角度名称、轻微平移/旋转相机、相同观看面的小偏差、微量缩放或裁掉一点边缘不算变化。不能只换人物、只换背景或只改变动作便把重复镜头判作通过。

镜头阶段：逐对登记前后真实机位位置/高度/朝向、可见面及构图结果，设计清楚不同的观察视角；同时改变景别，使主体画幅占比、裁切范围及信息层级有可观察差别。景别标签不同但实际裁切近似仍不通过。变化幅度由实际画面可辨认差异判断，不编造统一角度阈值。

生图阶段：本格实际提示词写清具体机位视角和景别，以及与前格区别所在。相邻格所需基准来自批准镜头；独立格仍可按既有批次机制并行，不为本规则无条件新增生图依赖。只有确实需要前格实图作输入时才登记依赖。

验收阶段：实际并排对照前后图片，逐项确认 adjacent_pair_basis（真实相邻格及版本）、camera_view_distinct（观看面/角度有明确差异）、shot_scale_distinct（主体比例和裁切有明确差异）、actual_composition_difference（不是仅标签不同）、physical_continuity_preserved（空间与人物连续性仍成立）。跨批次比较前一批末格与当前批首格。生成计划不同但返回图仍近似的，保持 HOLD。

这是用户明确指定的当前制作要求：替代较早“同景别正反打可直接通过”“不必同时改变角度和景别”的宽松约定；正反打也必须同时改变景别，不自动豁免。只准在锁定剧情、人物身份和真实空间内设计变化，不能为了变景别强行移物、扭曲遮挡或增加无关全景。若锁定脚本明确指定不变镜头并与此冲突，记录冲突，不擅改剧情，也不自行套用旧豁免。

相邻图的实际定位和版本/哈希记录在本次镜头或 QA 证据中；仅填写机位字段不同、景别字段不同不构成视觉通过。
