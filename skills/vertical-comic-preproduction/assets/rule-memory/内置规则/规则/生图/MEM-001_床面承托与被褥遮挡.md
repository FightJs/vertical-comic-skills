# 床面承托与被褥遮挡

适用：画面实际包含床上人物（含床上被褥遮挡人体）。被褥本身不意味着存在床：地铺、睡袋或地面盖被子的合法剧情不适用床规则，可对关键词召回说明排除。只在对白中提到床、人物实际躺在地面时，不得据此把人物移到床上。

镜头阶段：根据批准脚本和场景，建立或复用经核对的站位图。图中明确床体、床垫承托面、地面、人物躯干/骨盆相对床垫的位置、被褥覆盖范围、机位和可见区域；俯视图不足以表达高度时补侧面或高度标注。人物躯干不能被画到床外地面后靠被子掩盖。坐床沿、腿垂下等情况按真实动作分别解释，不能强制全身都在床垫上。

同一空间、人物位置与机位关系不变时可复用已有图；位置、床型、机位或遮挡关系变化时重新核对，不能照搬。站位图是推理与核查辅助，不是物理正确的证明。标注图不得自动上传为画风/身份参考；需要生图构图参考时另依既有参考合同制作、核对适用的干净画面图。

生图阶段：核对站位图和当前镜头一致，将当前画面可见的承托、床沿与被褥遮挡关系写入实际提示词，不能只写“人在床上”。近景允许床脚、地面在画外，不为证明空间而强制拉成全景。

返回图阶段：实际检查 support_surface（承托面）、body_on_mattress（躯干与床垫关系）、bedding_overlap（被褥前后遮挡）、bed_floor_relation（床与地面高度关系）、camera_visibility（本机位应见部分）。画外部分以获批空间依据支持，不凭空宣称看见；画面可见部分有矛盾则 HOLD，局部修复后重验。

承托检查要区分床垫平面、床沿高度、地面及被褥覆盖层：坐床沿时骨盆由哪一段床垫承重，双腿和脚落在哪里，不能靠被褥纹理把地面画成第二张床。近景只核对实际可见关系，不能因此强制露出地面。

连续睡姿按固定床头、枕头和床侧定位，床上其他在场者持续保留；画幅左右可随反打改变，世界床侧不随之改变。被角方向须与床轴、覆盖人体及真实褶皱相容，不按单条斜线机械判错。空间/人物不可见时记清裁切或真实遮挡依据，不虚报已核实。
