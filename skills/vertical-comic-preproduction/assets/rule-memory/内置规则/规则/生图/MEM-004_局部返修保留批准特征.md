# 局部返修保留批准特征

适用：对已返回图片进行局部修复。实际操作必须标记 operation=repair，无须在批准镜头中预先虚构返修事件。

生图阶段：记录明确修复目标、允许改动范围、必须保留的已批准特征及受影响连续性。每次实际调用继续提交原始批准画风和适用身份/衣装参考，不能仅以错误图为唯一依据。把当前修复范围和保留约束写入实际提示词。用户明确批准的换装、改构图等属于本次允许改动，不应被通用保留规则否定。

返回图阶段：检查 repair_scope（目标确已修复）、identity_preserved（批准身份）、style_preserved（原始画风）、costume_preserved（本次适用衣装）、unaffected_composition（未授权变化的构图与动作）。范围内变更记录当前授权依据，不虚报保留。修复成功仍需全套图片质量及邻格连续性检查。

一次针对性返修仍有同一问题时停止诊断，不无限抽卡。局部事实、具体错误格、人物与服装名称只写入生产任务，不进入通用规则库。

返修选择本格已记录的清晰原始返回底图，说明选择理由并保留此前有效修正；不机械沿用最早或最新版本。红字标注、缩略图不作底图。返回后在可比尺度检查焦内线条、首饰、手部及未授权区域，尺寸或PNG格式不能单独证明无退化。

既有图片按真实缺陷区分裁切候选、局部返修与需改镜头的重绘。图本身正确仅背景过多可提出裁切，保留必显信息、目标比例和有效像素；超出批准构图范围按原流程解决。不能裁掉关键手势或矛盾空间虚报修复。文件名“修改版”不代表修复或验收通过，原图保留、改版另存并实际查看。
