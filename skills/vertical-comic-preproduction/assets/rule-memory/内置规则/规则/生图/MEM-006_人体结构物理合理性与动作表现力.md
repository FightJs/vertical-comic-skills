# 人体结构物理合理性与动作表现力

适用：画面可见人物或身体局部，包括静止、动作、近景手部。镜头、生图、图片验收三个阶段均执行。

人体结构：检查可见肢体的数量、归属、连接、长度比例和形态，不得多肢、断肢、融合或穿插。检查肩肘腕、髋膝踝及颈部的连接和弯曲方向，姿态与人体活动范围相符；近大远小、透视缩短和真实遮挡不能误判为缺肢，也不能用“透视”掩盖错误连接。

物理关系：核对重心、支撑面、接触点、受力方向、动作轨迹与前后遮挡。行走、坐卧、牵拉等动作须有合理承托/受力，不漂浮、穿地或无因扭转。脚本明确的超自然动作按其设定表现，除此以外的身体连接、接触和遮挡仍要自洽；不得为修复姿态擅改动作结果。

表现力：人物意图、反应、发力方向和动作关键点应清晰可读，强弱与当前剧情和批准画风相称。不能以僵硬站姿应付应有的动作，也不能用夸张到失真的关节或与剧情不符的情绪增强效果。动作可通过肩线、躯干、重心、手势和视线表达，不只堆“有张力”等形容词。

镜头阶段确定可见结构、承托、动作关键点和情绪强度；生图阶段将具体可见动作、接触和表现写入实际提示词；验收阶段看实际图，逐项记录 anatomy_integrity、joint_pose_validity、physical_support_and_force、action_readability、expression_intensity_fit 的可观察依据。静态画面按静态意图核查，不强加激烈动作。

多人接触、床上承托等情况另外执行相应专门规则。失败只修实际问题及受影响范围，保留批准身份、服装和画风。

可见手部在原尺寸局部检查指掌连接、关节、握持与手臂归属。透视和遮挡有依据时不按可见指头数量机械判错；发现疑点再核对完整手臂及接触对象。背景可辨认手部同样检查。

可见手或接触动作的执行指令明确角色自身左右肢体、对象和部位、腕臂连接、接触方式及动作阶段，保留脚本动作结果；不能把按下画成悬空指向、握持画成靠近。角度遮住关键接触且动作不可读时先修候选机位。非剧情手部可在镜头设计中合理出画，但不得丢失关键动作/同时反应或裁切掩盖失败；不强求所有手展示五指。

动作可读不等于动作自然。持物围绕喝、递、读、操作等真实用途安排肘腕和手掌位置；突出物件用机位与裁切，不靠无依据的极端前伸、扭腕或改变物件尺度。全身可见时连查肩—髋—膝—脚朝向及支撑，不能只让脚满足指向而扭断骨盆与腿。

摄影机高度、头部朝向、眼神目标是三个不同事实：俯拍不能自动变成仰头看摄影机，反打不能自动改变对视对象。看不到目标不等于目标不存在，按原空间关系判断。

原尺寸检查裸露的眼部和指掌结构；真实头发/手/物件遮住的部分可隐藏，未遮住的区域缺眼、断掌或被涂抹则不能以“遮挡/风格/高清尺寸”放行。清晰度以可辨认结构判断，放大或锐化不补原生信息。对未知部位保留不确定，不能机械要求所有五指或双眼同时可见。

## 动作服从已有空间与承托

涉及踏、倚、撑、坐、跨越或远距离伸手时，明确身体部位、真实承托物及其具体表面。含糊名称先依参考和源稿解释为实体表面，不把地面平台、边缘或区域名称自动理解成额外凸起的台座。

人物伸手、脚步和承重必须与固定物体距离相容，不为实现姿态新增踏台、扩大桌面、延长台面或拉长肢体。前期发现冲突时，在批准范围内调整机位/表现或集中处理准确冲突；不得擅改源剧情动作，也不把全部姿态统一为双脚平站。只对实际发生承托或接触的可见部分执行本项，普通表情格不附加场景工程检查。

审核检查实际承托来源、接触、受力和肢体连接。返修时区分肢体本身错误与空间/承托输入错误；后者先修输入，不能只修手脚外形。沿本规则原检查项记录观察，不新增重复QA。
