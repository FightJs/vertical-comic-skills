# 镜面统一磨砂且不呈现真实反射

适用：画面实际可见镜子或镜面。镜头、生图、图片验收三个阶段均执行。

统一处理为磨砂、漫反射表面，不生成真实镜像，不出现可辨认的人物、脸、肢体、文字或场景倒影，也不把模糊程度很轻的真实反射当作磨砂。可保留符合批准画风的柔和无具体形象色块与亮暗变化。

镜头阶段：保留镜框、镜体形状、安装位置、朝向及真实遮挡，明确镜面为磨砂。生图阶段：在实际提示词写明“磨砂镜面、无可辨认人物或场景倒影、无真实镜像”；不得通过删除镜子、移动家具或扭曲镜框来消除反射。

验收阶段：核对 frosted_mirror_surface（磨砂外观）、no_recognizable_reflection（无可辨认倒影）、mirror_geometry_preserved（镜体及空间关系保留）、reflection_story_conflict（剧情是否依赖镜中信息）。不因为倒影看似好看或镜像方向正确而接受真实反射。

若锁定剧情必须通过真实镜中影像传达关键信息，明确记录与磨砂要求的冲突并暂停受影响项；不能自行恢复真实反射，也不能悄悄删除剧情信息。只有用户后续明确的范围调整可以解决冲突。此条只约束镜子，不自动扩展为所有金属、水面或玻璃材质禁止反光。
