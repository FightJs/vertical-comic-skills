# 掌掴完成后的结果瞬间表达

适用：源脚本明确掌掴已经发生，且本格重点是结果、人物反应或双方关系变化。责任阶段为生图，镜头、生图、图片验收三个阶段执行；按实际条件命中后读取，不作为所有人物格的阶段预读。

## 适用判断与原稿边界

source_action_phase：先核对本格动作是已完成、准备中、未接触、被阻止还是未打中。只有已完成且允许以结果瞬间表达时，标记 slap_completed_result。关键词“扇巴掌、掌掴、耳光、打脸”只作辅助召回，不能据此断言已经打中。对白提及、回忆叙述但本格不展示，以及比喻性的“打脸”不适用；纯关键词误召回按现有合同记录 NOT_APPLICABLE 和具体依据，不标该语义标签。

源脚本原文、格数、格序、文字和动作结果保持不变。准备动手、挥掌未落下、被抓住手腕、被躲开或挡住的格，不能改成已经打中。原稿必须展示实际接触瞬间、连续动作拆格或时间顺序与本方法冲突时，保留准确原意并按现有受影响镜头流程处理，不套用本规则擅改剧情，也不新增统一人工停点。

## 镜头与生图

single_result_instant：优先定格在动作完成后的紧邻瞬间，不硬性设为整整一秒之后。实际绘图执行段尽量不重复“扇巴掌、挥掌打脸、手掌击中脸颊”等动作过程描述，改为清楚描述最终可见姿态。锁定源文仍保存在源记录中，不用改写原文掩盖差异。每格只表达一个瞬间，不同时要求挥掌、接触、收手，不用残影、多重手臂或连续动作分身表现过程。

hand_arm_ownership：写清执行动作的人、角色自身哪只手，以及完成后手停在何处。选择一个明确位置，不把“收回或伸出”等多个候选姿态交给模型。手臂须自然连接所属人物的肩、肘、腕、掌，动作手已与对方面部分开；不得接错人、增生手指或混成共用肢体。左右侧与停手位置来自本格已确认动作依据，不机械套用示例。可见手指按真实角度和遮挡检查，不强求五指全部露出。

support_and_reaction：按剧情具体描述承受动作者的头部偏转、视线、表情、躯干与重心，以及双方距离、朝向和必要遮挡。颈部转角、身体连接、脚底或其他承托关系必须合理，不把收手后的姿态画成持续推脸、抓脸、扭颈或全身无依据飞出。

no_unapproved_injury：不自行增加红肿、掌印、出血、掉牙、摔倒、夸张甩头或新的伤势。原稿或准确批准依据要求这些结果时才表现，不用通用规则删除剧情已有结果。人物身份、当前衣装首饰、画风、场景和光照仍按本格批准依据保持。

生图阶段将本格具体结果姿态、手臂归属、反应与承托等适用约束写入真实 prompt，并按现有 memory_applications.generation 逐项记录；索引匹配或正文已读不等于已经执行。

## 图片验收

五项检查分别记录实际观察：source_action_phase（源稿确已完成且当前图未改成未打中或反之）、single_result_instant（仅一个结果瞬间，无多阶段残影）、hand_arm_ownership（沿肩—肘—腕—掌确认归属和数量）、support_and_reaction（反应、颈部连接、重心、距离与承托合理）、no_unapproved_injury（没有无依据新增或删掉伤势结果）。

打开实际原图检查整体反应和位置；手部、袖口、前臂连接有疑问时看原尺寸局部。写清看见的部位、归属和问题，不只复述预期姿态。结果图未表现原稿后果、仍有手部接错或不合理身体连接时判相应检查失败，不能以“已改成结果瞬间”为通过依据。结论绑定实际图片哈希，沿用原 QA、MEM-006 和适用其他规则；不增加独立放行或额外返修轮次。

本规则只保存跨话跨作品的表达方法。具体人物、左右手、表情、伤势与停手位置留在当前镜头及生产记录，不回写本库；不替代 MEM-006 的通用人体判据，确有多人接触时仍按 MEM-002 核对。
