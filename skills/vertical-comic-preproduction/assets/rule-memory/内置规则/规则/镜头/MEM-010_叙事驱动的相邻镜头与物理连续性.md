# 叙事驱动的相邻镜头与物理连续性

适用：源阅读顺序中的每一对真实相邻格；跨批次、换场景或执行者交接不重置。首格确无前格时不触发；跨话明确承接时继续核对。

v2要求：相邻镜头以本格叙事信息、最小充分裁切和真实物理连续性为先，不再强制机位/观察视角与景别同时变化。有脚本依据的连续近景、同景别正反打、说话者与听者反应可以成立，无需逐对申请此类例外。不能为了制造变化扭曲身体、搬动家具、丢失在场者、扩大狭小空间或插入无关全景。

镜头阶段：按源稿核对焦点、反应、动作阶段和必要信息，记录实际机位/可见面/裁切及adjacent_change_reason。已建立空间的对话优先评估足够表达本格信息的近景；腿脚、路径或空间本身承载信息时保留必要范围。只改镜头签名、标签或微量缩放不是叙事依据。完全相同构图且无可观察信息变化仍按已有格对例外合同处理；本规则不授予添加动作、情绪或剧情的权限。

生图阶段：正文执行本格批准的具体机位、裁切与可见动作，不追加“必须换景别”。同场景关系沿批准状态保持；普通独立格可并发，本规则不自动建立前图输入依赖。

图片验收逐项核对：
- adjacent_pair_basis：真实相邻格、当前图片版本及比较对象准确。
- narrative_coverage：镜头覆盖本格必要信息；变化或保持有源剧情依据，没有意外复制默认视图。
- framing_economy：裁切足够而不过度，不为制造差异额外展示全身或房间；必显信息未丢失。
- physical_continuity_preserved：人物、道具、承托、固定空间与真实遮挡保持或按有依据的动作改变。

机位/景别changed=false是观察事实，不单独构成失败。实际图片仍必须与批准构图和本格必显信息相符；不能用“允许同景别”为重复默认全景或省略动作开脱。相邻比较与同场景状态比较各按实际证据执行，不以屏幕左右变化证明世界移位。

版本边界：用户于2026-10-19批准优化方案后授权实施，本v2替代新任务中v1的双变化要求。旧冻结RV及快照仍保留v1判据、批准和历史记录；不得给旧图自动改判PASS。无需为本规则新增辅助图、表格或人工停点。
