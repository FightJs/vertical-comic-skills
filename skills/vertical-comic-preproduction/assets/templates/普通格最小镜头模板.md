# 普通格最小镜头模板

普通格仅填写以下五项创作内容，格号及原文由源快照带入，不重新抄写。不另写镜头解说、创作理由、备选机位或细节审查长文。

| 人物 | 关键动作 | 景别 | 必要背景 | 参考 |
|---|---|---|---|---|
| 本格实际出镜者及当前状态，引用已确认身份 | 一个关键动作或反应；保留剧情必显内容 | 能看清动作的最简单景别 | 交代地点/剧情必需的背景；无额外布景设计 | 现有适用人物/衣装/场景/画风参考，沿原参考合同 |

同场景普通格先用一个实际代表格贯通原候选入口，把共同机位、裁切默认、画幅、身份/场景设置和技术包头放入主表shared。其余格只填差异，不逐格复制和重新设计共同字段。复杂接触、关键物件或剧情空间问题只补该格必要条件；不把普通格一律升级成复杂设计。

工具支持以下模板写法（示意字段值必须替换为本格真实内容）：

```json
{
  "panel_id": "P002",
  "shot": {
    "$shared": "本场景普通镜头模板",
    "$overrides": {
      "panel_id": "P002",
      "locked_script": "源快照中的本格原文",
      "shot_scale": "medium_close",
      "visual_focus": "本格关键动作或反应"
    }
  }
}
```

这里只展示镜头模板部分。完整主表仍有execution、packet_header、render_mode等原字段；共用字段引用shared，不新增第二套镜头表。人物、动作、背景及参考需要变化时，在对应原字段写准确差异；数组和对象整项替换，避免遗留前格人物或动作。模板中的机位只用于实际适配的同场景普通格；不能由工具猜测新场景位置或复制前格剧情。

五项内容明确且原必要校验通过就停止设计，进入增量派生和交接。没有删除源格、源文、批准或必要引用字段，也不缩短实际提示词、不减少参考和补资产范围。
