# 速度优先的轻审核成品

新任务的默认返图审核为 `light_story_review_v1`。用户要求每图快速看一次，只修影响剧情理解的严重问题，最多一轮；不再用全面细节审查作为默认生产目标。这一规则优先于旧文档的六项QA、原尺寸局部取证、逐MEM观察、整话/跨话重复视觉复审及批量前真实返修演练要求。输入批准、源格完整性、真实调用记录仍沿用已有工具；不要重新制作已审输入。

## 启动与范围

`comic_start.py prepare` 默认使用轻审核，也可显式传 `--image-review-profile light_story_review_v1`。低层 `init_preproduction.py` 兼容入口需显式传此参数。状态的 `image_review_profile` 冻结本次审核范围，接包自动沿用。用户明确要求全面精审时才使用 `--image-review-profile full`。没有该字段的旧冻结任务仍执行原审核；不要手改在途状态或将新QA装入旧包。

前期继续复用批准资产和主表，不做可选润饰、额外构图图或无实际问题的返修演练。复杂格在首批正常生产中验证，必要返修只针对真实严重问题；不单独生图测试返修接口。输入层正式合同尚未变化，不声称前期所有检查已经取消。

## 看图与处理

每个实际返回图只做一次全图快速观察：人物是否明显错认；关键人物、动作对象、剧情信息是否可读。可以把若干原图同时打开，逐格各留一句观察。不逐格放大检查饰品侧别、指形、材质、微表情或像素级画风，不补逐项MEM及六维证据。只有影响剧情判断的局部确实看不清，才局部查看。

普通美观问题、轻微配饰/衣装/画风/背景差异直接留人工。主体可识别、剧情可理解时，轻审核可以PASS且带问题；这不是六项全面精审PASS，问题不得删掉。严重问题写FAIL并做一次有明确目标的修复；修后只再快速看一次关键动作与人物，没有改善则保留较可用版本和真实遗留问题，不追加轮次。仍影响剧情的遗留图标注人工优先处理，不能宣称全部可用。

普通连续性偏差不追查前序全链，不等待整话或跨话全面复审。仅当当前图片显现影响剧情理解的矛盾时，查看必要前图帮助判断。真实生成依赖仍保留，不能用未返回或未知图片当参考。

返回即保存并释放槽位；审核、下一格生成和增量归集沿现有调度独立推进。最终检查源格是否齐全、文件可读、实际采用版本、哈希和容器，不再做一轮全图复审。交付索引和问题表注明轻审核范围。

## 登记入口

使用原 `production_runtime.py --action review --prepare-qa`；轻审核会生成精简模板，队列动作为 `REVIEW_STORY_ONCE`。随后使用原 `review_pipeline.py --state ... --expected-state-sha256 ... --observations ...` 一次保存QA、问题决定、采用和归集。观察文件示例（示例内容不能冒充实际观察）：

```json
{
  "panel_id": "P001",
  "attempt_id": "P001-r1",
  "base_qa": null,
  "qa_template": {"path": "实际模板路径", "sha256": "实际哈希"},
  "reviewer": "实际审核者",
  "reason": "本次实际观察摘要",
  "verdict": "PASS",
  "adopt": true,
  "light_observations": {
    "checks": {
      "identity": {"status": "PASS", "observed": "本图实际人物观察"},
      "story_readability": {"status": "PASS", "observed": "本图实际动作与剧情观察"}
    },
    "issues": []
  }
}
```

普通问题的 `issues` 只填 `location`、`problem`、`target`、`story_critical:false`，工具自动产生留人工决定，不另填六项、问题表和采用引用。有严重问题时标记 `story_critical:true`，对应检查与verdict为FAIL；首轮附原生产决定格式的具体修复方案，仅 `fix_now` 引用严重问题，`opportunistic` 留空。观察引用使用 `/light_review/issues/0` 等。无法修复且选择停止时明确填写停止原因；不得用普通瑕疵触发修复。第二轮工具拒绝继续自动返修。修订使用准确 `base_qa`，原图、旧QA、次数和采用历史保留。

新任务改按[四小时完整交包](runtime-clock.md)，自然时间计时并提前收尾；只有全部源格完整且按时交付才算完成。旧冻结任务保持原时钟，不增加达成率统计。减少审图、取证和返修工作量，不能保证外部生图服务响应速度，也不承诺未经实测的节省百分比。
