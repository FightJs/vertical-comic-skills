# 累计有效运行计时

仅用户提出运行时限时启用；默认额度14400秒（4小时），前期和生产各自建立账本。多话/工作agent共用同一职责账本，不相加。服务等待、校验和返修计时；明确人工暂停及等待用户不计时。时间额度不替代预算或授权，不保证外部服务能按期完成。

## 新运行

`comic_start.py prepare ... --runtime-limit-seconds 14400` 或 `receive ... --runtime-limit-seconds 14400` 在本地运行的 `00_任务协调` 建立 `runtime-clock.json`。账本在输入校验后、创建快照/解压前启动；调用入口前的会话分析尚不在自动计时范围，不能宣称覆盖了整个会话。需要包含更早的准备工作时先显式初始化对应协调目录并start，不得事后猜测补时。

返回 `clock_directory`。实际执行前核实当前宿主session_id，再用 `runtime_clock.py bind --directory <目录> --session-id <准确ID>` 绑定；也可启动时传 `--clock-session-id`。环境中的线程ID只有核实与Hook的session_id一致时才能使用，不按书名或最近目录猜绑定。一个会话只绑定一个当前职责，切换先显式unbind，不自动替换。

## 界面停止接线

安装工具 `tools/sync_skills.py --clock-hooks` 或已安装的 `runtime_clock_setup.py --apply` 会备份并合并用户 `hooks.json` 中的Interrupt定义；其他Hooks保留。默认不改Hooks。非管理Hook需要在Codex界面审阅并信任准确的定义，安装器不能代替信任。更改定义后可能需要重新信任。官方来源：https://learn.chatgpt.com/docs/hooks

Hook收到Interrupt时只原子写入短暂停事件，不取生产锁、不调用生图、不终止已提交请求；记录的是收到事件时间，不冒充按钮点击的精确时间。异步写入不受协调锁阻塞。自动接线是否有效必须用真实停止按钮测试，`hook_event_observed`只证明收过事件，不等于完整生命周期验证；`automatic_pause_verified`不会因配置文件存在而置为true。

没有支持/信任/绑定时明确提示自动扣时不可用。用户可先执行 `runtime_clock.py pause --directory <目录>` 再暂停。不能用消息间隔、心跳消失或后台进程仍活着推断暂停。

## 恢复与查询

- 人工暂停后只问进度：查询status，保持PAUSED；不自动恢复生产。
- 用户明确恢复原任务或授权继续实际工作：先运行task_coordination.py resume核对旧任务/未知请求，然后 `runtime_clock.py resume --directory <目录>`，再继续。不重置attempt、调用、额度或历史事件。
- 明确等待用户：wait_user；得到必要答复且恢复实际执行时resume。
- 多次相同event_id幂等，冲突动作拒绝；不同ID的重复pause/resume不会重复扣时。
- 已通过真实完整交付校验后记录finish；未完成但停止工作时pause，不用finish伪装完成。
- 单调时钟与墙钟共同核对时间；可取得boot标识时校验重启。宿主/boot变化、计时不连续或墙钟明显跳变报告TIME_UNCERTAIN，不伪造精确时长。异常退出且没有中断事件不能自动扣除离线时间，需核对时间证据，不能重建账本清零。

## 暂停与生产边界

新工具在领取及IN_FLIGHT登记边界检查计时。暂停、未开始、时间不确定或额度用尽时不新增领取/调用；原来已提交的远端请求仍可能继续且计费，允许保存、查证及落账。恢复前先查证，禁止重发未知请求。最后一次检查到外部工具实际接收之间仍存在宿主调用边界，不能承诺撤回已发出的请求。

旧冻结工具不热替换，也不会因为上层新账本自动获得所有检查；接包使用旧冻结入口时，总控必须在实际工具调用前用安装版 `runtime_clock.py check-submit --directory <目录>`。该返回只允许紧接着的一次调用，不保存为长期许可。外层Hooks不能在总控停止后保证所有旧工作agent/外部服务立即停止；须在委派时传入同一目录并要求每次提交前检查。尚未接入的调用路径明确标注，不能宣称全链路原子暂停。

生产指标分别报告自然经过/有效运行/排除区间；有效运行不等同CPU耗时或服务计费时长。到期禁止新增调用，保留收图、记账、校验和打包能力；不能保证这些收尾都在额度内，超额如实报告。总控据剩余时长提前预留收尾时间，不为赶时限跳过必要审核。

## 最小验证

不生图：真实停止一次，间隔后明确恢复，核对Interrupt事件、累计秒数和暂停区间。另测重复事件、并行共用额度、暂停期间返回保存、到期拒绝新请求、重启/时钟异常。仅模拟Hook载荷不算真实按钮接线通过。
