# 按本格必要信息选择构图

按 [生图输入优先级](production-foundation.md) 选择真实空间内的可行机位和裁切。完整展示不能成为移动固定家具、消除遮挡或扭曲身体的理由；必要动作、接触和同时反应无法从一个合理视角呈现时，在镜头记录中保留受影响格的冲突，不拼接不兼容的视角。

适用于逐格镜头候选、B 提示词和返回底图审查。规则依据：用户于 2026-10-09 确认，竖屏对话格优先中近景、特写和明确半身构图；全身与全景按本格必要信息选择。保留脚本格数、文字、动作结果、规定的同时反应、空间位置和真实遮挡。

## 先决定需要看见什么

先写本格唯一主要视觉重点，以及必须入画的信息，再选足够覆盖这些信息的最小取景范围。选择由原脚本动作、接触点、情绪呈现或空间信息支持，不按固定景别比例配额，也不机械轮换全景、近景和特写。

两人说话可以是说话者、听者反应、过肩局部或双人半身。对方在场不等于必须每格完整同框。需要同时看见双方反应或互动时，保留必要的双人覆盖。将画外人物保留在站位/连续性记录中，台词归属和读序保持不变。

## 景别与身体裁切分开记录

`shot_scale` 表示主体在画幅中的尺度；`framing.body_crop` 表示具体露出范围。写明腰以上、胸以上、肩以上、面部局部、手部或物件局部。双人或多人裁切不同时，各角色还须在 `characters_visible` 中说明自己的裁切范围；`mixed` 本身不足以执行。

| 本格必要信息 | 优先构图 | 使用条件 |
|---|---|---|
| 表情＋手势或上半身体态 | 腰以上半身 `waist_up` | 腿脚/地面不承担信息，必要手势与道具完整入画 |
| 情绪反应、视线、停顿 | 胸以上 `chest_up` 或肩以上 `shoulders_up` | 必要信息集中于脸、头部与肩部 |
| 微表情、眼神、面部细节 | 面部特写 `face_detail` | 需要的局部清楚可辨，完整上半身没有必要 |
| 递物、握手、操作屏幕 | `hands_detail` / `object_detail`，或能容纳接触点的半身 | 判断是否还需连同表情一起看；不得裁掉关键接触关系和画内文字 |
| 走动、跪下、踢腿、重心或完整姿态 | 全身 `full_body` 或足够覆盖动作的构图 | 腿脚、轮廓、服装全貌本身承担剧情信息 |
| 地点、距离、路线、多人空间关系 | 环境构图 `environment` 或必要的宽景 | 整体空间关系是本格的必要信息 |

半身适用须同时满足：必要信息能在头/躯干/手部范围内表达；腿脚和地面关系不承担关键信息；裁切不遗漏必要道具、接触点、画内文字或同时反应。若仅需面部信息可更紧；若腿脚或空间承担信息应扩大到足够范围。

全身与全景分别判断。紧凑的单人全身不要求展示整个房间。每个全身/宽景候选都填写 `wide_or_full_reason`，说明具体必显信息；“增加变化”“两个人在说话”“在房间里”本身不足以要求扩大画面。

狭小空间已经建立后，连续对话优先评估人物近景、反应特写和接触局部，减少反复重建全房间的透视。空间建立、位置变化、路径或完整动作确实承担信息时才扩大。源稿明确要求的脚向、落脚点或承托信息不能因为难画而偷偷裁掉；必要适配在B先解决，失败图不靠遮掉错误获得通过。

## 背景减法与空间连续性

`background_level` 使用 `establishing`（必要空间建立）、`anchor_only`（少量可识别锚点）或 `minimal`（仅取必要的少量背景）。新地点、位置变化和路径关系按需要建立空间；已建立地点的对话通常保留必要锚点；情绪特写可通过紧凑取景减少其余背景的入画面积。必须入画的门窗、危险物、线索和场景文字始终保留。

完整场景账本与站位图保持不变。旧策略简化来自机位和取景；新background_policy按[背景模式](background-treatment.md)允许绘制省略，但不移动实体、不改变世界事实、不解除真实遮挡。不要把镜头外的全场人物/道具清单粘进提示词。参考资产用于身份、风格和空间连续性；全身角色板不会授权画出本格未选择的腿脚。

## 相邻格变化

相邻机位与景别按本批冻结的MEM-010版本设计。v2以叙事和物理连续性为先，允许有依据的连续近景、同景别正反打，不要求两项同时变化；无需为这种正常设计逐对申请例外。旧v1冻结任务仍按原双变化合同恢复。取景保留本格最小充分信息，不为变化扩大裁切或改变物理空间。

填写 `adjacent_change_reason`，并以实际焦点人物、相机位置/朝向、裁切、可见动作/反应或背景变化核对理由。只换签名、格号或近义标签不算变化。完全相同构图且没有可观察的信息变化时，须给该格对登记 `camera_exception_approval`：`panel_ids`、`event_path`、真实 `sha256` 和 `status=USER_ACCEPTED`。文件与批准范围均需实际核对；填写字段不等于用户批准。空间 HOLD 不被镜头重复批准解除。

## 逐格记录与人工审阅

新镜头表和新提示词索引声明 `framing_policy=information_first_v1`；每格填写：

```json
{
  "framing": {
    "focus": "说话者的表情与持杯手势",
    "focus_subjects": ["CH-001"],
    "required_visible": ["说话者表情", "持杯手与杯子"],
    "body_crop": "waist_up",
    "crop_reason": "本格信息位于上半身，腿脚不承担动作；杯子与手完整入画",
    "background_level": "anchor_only",
    "background_treatment": "clear_limited",
    "wide_or_full_reason": ""
  },
  "adjacent_change_reason": "说明当前真实机位、景别与前格的具体差异，并逐项核对适用规则"
}
```

这只是字段示例，实际内容须来自本格脚本；不要把示例手势、杯子或人物 ID 填进作品。缺字段的历史包需复核并补证，不能直接伪填新字段或改动已批准镜头。

审阅版包括逐格原稿—候选对照、明确的身体裁切与必显信息、全身/全景理由和未决项。逐格规划是否新建、复用或无需额外干净摄影机视角构图参考；复杂接触/遮挡或现有参考不足时按 [codex-imagegen.md](codex-imagegen.md) 制作并核对，不强制每格新画。未知空间关系保持候选。确认后，逐格 JSON、提示词和清单沿用同一记录；有真实返回图时再制作缩略总览与对照图。

返回图片逐格核对：裁切是否扩大、画外人物是否被补入、必显信息是否丢失、背景是否扩大，以及真实相邻变化是否满足当前规则及准确批准例外。机器核验字段和证据一致性；实际看图和用户批准仍分别记录。

## 主体突出与清晰背景

新任务镜头优先用近景、半身近景和表情特写突出人物与关键动作；空间建立、路线、承托和必要同时反应决定是否扩大。不设固定80%/90%主体占比，不把每格改成大头特写。全话仍执行frame-ratio-plan，不照搬案例的横版比例。

在visible_region写清上/下缘、主体位置、必显动作和本机位真正可见的背景区域。background_level表示信息量；framing.background_treatment表示呈现方式。新narrative_background_v1候选按叙事选择四种背景模式，近景优先评估scene_softened；必显信息与物理关系决定保留范围，具体字段见[背景模式](background-treatment.md)。旧clear_limited保持少量清晰背景规则。特殊获批景深选approved_depth_of_field，并以background_treatment_basis写本格批准设计依据；文字存在不证明批准真实。

非剧情手部可在设计阶段合理置于画外；不能在失败后裁掉必显手、接触点或同时反应来获得PASS。新构图先设计再生成；现有图裁切候选另按stage-image-review处理，审阅截图不作成品。模块见prompt-package.md。旧批准包不自动补字段重签，新增或迁移候选才采用并走现有准确范围批准。

## 生成前可实现性核对

逐格用同一次镜头审阅核对：裁切能否包含全部必显接触；机位是否能看见指定对象正面；反射与实体视线是否一致；固定家具能否承托动作；实际工具输出尺寸能力是否支持。胸上特写与膝上交手、背向电视与电视正屏等冲突在B前给具体方案，不留到返图反复试。

动作先于景别标签：坐姿低位接触与“腰上”、肩上近景与必要双手等不相容时，B先解决范围；不能等返图后把消失动作当成合理裁切。保留批准比例计划，但不因交错或相邻差异要求而扩大身体范围、移动家具或强扭人物。沿framing_feasibility记录真实判断，不另建可行性审批。

裁切必须同时容纳必显信息：胸上裁切不能声称展示腰部或自然下垂完整手指尖。需要下沿到上腿时用现有mixed与逐人物明确边界，不抬手迁就裁切或擅自扩至膝部/全身。脸不可见与身份可辨分别记录，见[最终输入审查](final-input-semantics.md)。
