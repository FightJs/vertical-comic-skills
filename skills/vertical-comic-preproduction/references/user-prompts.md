# 五类常用短指令

这是随Skill安装的使用模板，无需用户提供外部Markdown文件。仅在用户请求对应操作时执行该节；介绍、查看、整理模板不启动实际任务。用户本次明确要求优先，不扩大到其他阶段。

| 用户说法（已明确指条漫Skill） | 执行章节 |
|---|---|
| 帮我更新／更新五件套 | 第2节：更新；采用main（preview），用户明确要求stable时按其选择 |
| 帮我进行初次配置／首次配置 | 第1节：安装与可选配置；已有可用安装则复用，不因配置而自动更新 |
| 帮我进行前期制作与交接，【书名】的【E001–E005】 | 第3节：从本书配置和准确话号开始，止于正式前期交接 |
| 帮我进行接包生图与完整交付，【本机交接包路径】的包内全部话 | 第4节：接包至完整成品；不要求外部脚本、资产或本书配置 |
| 把【指定提示词／文件段落】提炼到用户增补 | 第5节：只处理用户指定内容 |

短指令按下方对应模板展开即可，不要求用户再粘贴长模板。必需信息从用户消息、已保存配置或已验证交接包读取，确实缺少时一次性询问；输出位置未提供时使用Skill默认值。不要把【占位符】当作输入。没有明确条漫上下文的泛指“更新”，不能据此更新五件套。

前期与生图模板默认委托执行者内部审查并真实记录决定，累计有效运行上限各4小时；用户明确保留亲审节点或另定时限时按其要求。已存在的RV沿用冻结合同及实际授权，不以短指令重置历史或改写冻结工具。

仅初次配置时保存本书配置，不调用会创建RV的prepare入口，不启动制作。若当前版尚无独立配置命令，按comic_start.py的既有profile格式，在用户明确的项目目录下保存`.comic/books/<书名UTF-8的SHA256前16位>.json`，字段为`policy=comic_book_profile_v1`、`book`、`script_path`、`asset_root`；路径须先验证并转为绝对路径。同书已有配置复用，路径冲突集中核对且保留旧文件。不要为保存配置调用prepare，也不要以quick-start的首次制作流程扩大本次职责。已安装的入口不能替未安装用户自行触发；首次安装仍需用户提供仓库链接或安装要求。

执行时复用现有实现，不新增生产流程：环境及书籍配置见[短启动](quick-start.md)，更新见[安装更新](installation-update.md)，计时见[有效运行计时](runtime-clock.md)，用户增补见[内置规则维护](builtin-rule-maintenance.md)。计时能力按实际安装版本核实；没有已验证的有效运行计时及暂停接线时，不声称已经自动扣除暂停。实际规则与工具能力不足时如实说明，不伪造批准或完成。

## 1. 初次安装与可选配置

“接包生产”或“暂不确定”可删除书名、脚本、资产字段。

```text
请从 https://github.com/FightJs/vertical-comic-skills
安装完整条漫Skill五件套，明确使用main（preview通道），
自动准备独立Python依赖环境并检查安装结果。
先备份已有安装，保留本地修改、用户增补规则和书籍配置，冲突不强制覆盖。

使用职责：【前期制作 / 接包生产 / 暂不确定】
仅前期制作需要配置：
书名：【书名】
脚本：【本机脚本绝对路径】
资产：【本机资产目录绝对路径】

其余使用默认值和内置规则，校验路径并保存本书配置；缺少的必需信息一次性问我。
接包生产或暂不确定则跳过书籍配置。
本次只安装和配置，不创建RV、不接包、不启动前期制作或生图。
```

## 2. 更新五件套

```text
请从 https://github.com/FightJs/vertical-comic-skills
更新完整条漫Skill五件套到本次核实的远程main最新提交，
明确使用preview通道，不默认下载旧稳定Release。

先备份，保留本地修改、用户增补和书籍配置，冲突保留双方，不强制覆盖。
使用仓库更新工具，准备或复用独立Python依赖环境，适配当前操作系统。
GitHub匿名API限流时，改用已核实的main提交ZIP及仓库安装工具，不反复重试API。
校验五件套完整性、清单哈希、依赖环境、版本及来源提交。

本次只更新和检查，不创建生产任务、不启动前期制作或生图，
不修改现有RV的冻结工具、规则及生产状态。
```

## 3. 前期制作与交接

已有本书配置时使用。没有配置，可在同一提示词中补充脚本与资产路径。

```text
使用 $vertical-comic-preproduction。
使用模式：分工制作；职责：前期制作与正式交接。

书名：【书名】
话号：【例如 E001–E005】
使用已保存的本书配置。
输出位置：【可选；未提供则使用Skill默认位置】
采用默认配置和内置规则，建立新RV，保留已有文件。

完成输入审计、视觉基准、镜头设计及逐格生图包。
委托执行者内部审核A、B、实际提示词和交接材料，不设中间人工确认节点。
脚本与资产冲突优先按脚本补必要状态，内部审核后继续；真实记录委托决定。

先贯通代表性复杂格，再批量展开；普通格最小充分设计，只更新变化格及真实依赖。
前期收敛完整提示词、参考、连续性、服装配饰身体锚点与可见性及审核判据。
保持源脚本、格数、格序和文字不变。

包内携带全部生产必需材料、冻结工具与规则，明确依赖格的执行条件。
接收者无需配置外部脚本、资产目录或本书配置。
交付前完成不依赖原输入目录的真实接收端演练，不将候选冒充正式包。

启用累计有效运行计时，上限4小时（14400秒），人工暂停和明确等待用户期间不计时。
计时接线未验证时如实说明，不虚报自动扣时。
提前预留最终校验和打包时间；到期停止新增调用，继续必要收尾并如实报告缺项或超时。
减少重复工作，不跳过必要审查，不以进度汇报代替交付。

最终交付一个完整正式交接ZIP，内置说明、清单、决定记录、预算历史及发布演练证据。
持续推进并汇报进度，任务及工作子agent未收敛时不提前结束。
本次不启动正文生图；必要资产补图单独如实记账。
```

## 4. 接包生图与完整交付

可提供正式ZIP、完整解压目录，或新版微信运输包任一卷；分卷须全部下载到同一目录。

```text
使用 $vertical-comic-preproduction。
使用模式：分工制作；职责：接包生产、审核与完整成品交付。

交接包：【本机交接包路径】
接手范围：包内全部话、全部源格。
输出位置：【可选；未提供则使用Skill默认位置】

校验清单和发布证据，自动恢复、解压、绑定并预检，建立独立本地运行，保留已有文件。
直接使用包内材料、适用批准、冻结规则和生产入口，
无需配置外部脚本、资产或本书配置，不重做前期A/B。

委托执行者完成全部生产、自审、预算内必要返修及打包，不设中间人工确认节点。
不转交前期负责人；必要调整在保留剧情意图、人物身份和关键连续性的范围内自行闭环，
记录依据，仅重检受影响范围，不伪造人工批准。

每次生成和返修实际携带适用参考，保障人物、衣装配饰、空间和前后格连续性。
按实际容量、预算及依赖并发推进，可使用工作子agent，由总控持续协调。
审图同时核对实际成品、批准参考、本格判据及必要前序图；关键部位看原尺寸。
优先修重大问题，普通瑕疵记录，避免无收益的反复重生。
保留历史调用、预算、attempt和未知结果；未知请求先查证，不盲目重发。

启用累计有效运行计时，上限4小时（14400秒），人工暂停和明确等待用户期间不计时。
计时接线未验证时如实说明，不虚报自动扣时。
提前预留收图、审核和打包时间；到期停止新增调用，继续必要收尾并如实报告缺项或超时。
不跳过真实审图、调用记账及最终校验。

保持源脚本、格数、格序和文字不变。
每话分别保存进度及独立PNG，最终汇总完整成品ZIP，不拼接、不添加气泡或文字排版。
核对全部源格覆盖、采用版本、哈希及CRC，不以少量阶段包代替完整交付。
持续汇报进度，任务或工作子agent未收敛时不提前结束。
最终提供ZIP路径和简明质量说明，不把缺格或有遗留问题的材料宣称为全部合格。
```
