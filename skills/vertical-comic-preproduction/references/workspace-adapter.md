# 工作区适配说明

## 当前路径

当前排版工作区默认位于：

`B:/PCshare/AI条漫策划阶段/00_排版电脑生产工作区_RV_v003_20260922`

Skill 不应把该盘符写死到生产结果。新电脑上应根据当前 `AGENTS.md` 找到工作区根目录，并把路径写入本话配置。

## 参考优先级

1. 当前用户明确要求、当前批准脚本和本书当前有效资产；
2. A《示例作品A》和 B《示例作品B》的原始生产记录、用户确认样张和实际证据；
3. 已验证的跨书通用方法；
4. 旧交接包；
5. 《宝宝乖》和《爷爷逼我闪婚》旧电脑历史文件只能作为输入或历史材料，不能作为通过样张。

## 与排版工作区的边界

当前五件套终点是经过用户验收的逐格成品图片包。它不制作对白、心声、气泡、后期特效字或最终PSD；用户自行拼接并加气泡，不自动进入 C 阶段或调用 finishing Skill。旧 B 包和 C 放行名称仅用于兼容已有数据。

## 镜头权限和批准状态

当前工作区的 B 提示词规则要求每格绑定批准镜头、站位和可见机位。此 Skill 增加了“镜头改编候选”阶段：

`原脚本镜头 → 镜头改编候选 → 用户确认/锁定 → 站位与逐格空间记录 → B提示词`

未锁定前，提示词必须保持 `CAMERA_CANDIDATE` 或 `CAMERA_HOLD`，不能伪装成已批准机位。锁定后才允许通过既有的提示词包门禁。
